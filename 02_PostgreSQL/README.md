# PostgreSQL Learning

This repository contains my PostgreSQL and SQL learning notes,
commands, queries, and practical exercises.

## Structure

```
postgres/
│
├── README.md
├── .gitignore
│
├── 01-databases.sql
├── 02-tables.sql
├── 03-constraints.sql
└── 04-queries.sql
```

No per-topic folders — each topic is a single `.sql` file at the repo root, covering all the operations for that topic:

- `01-databases.sql` - Database creation, deletion, and listing
- `02-tables.sql` - Table creation, modification (ALTER), and drop
- `03-constraints.sql` - Primary key, unique, foreign key, check, default
- `04-queries.sql` - Filtering, sorting, and distinct results
